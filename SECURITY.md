# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive permission issue within this utility, please **do not open a public issue**. 

Instead, report it privately via GitHub Security Advisories or reach out directly to the repository maintainer. 

We take device integrity and data privacy seriously, especially when interacting with phone storage partitions and debug bridges. All reports will be evaluated promptly.
